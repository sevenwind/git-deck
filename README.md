# GitDeck

Нативный macOS-клиент для Git на SwiftUI: быстрый доступ ко всем репозиториям в рабочих папках,
визуальные изменения, история, ветки, stash, теги, хуки и встроенная git-консоль.

Требования: macOS 14+. Сборка — только Command Line Tools, Xcode не нужен.

## Возможности

### Репозитории и рабочие области
- **Рабочие области** — выбираете папку, GitDeck находит все git-репозитории внутри (глубина поиска настраивается, 1–10).
- Поиск по части названия репозитория, счётчик найденных, бейдж с числом изменённых файлов.
- Отдельные репозитории вне рабочих областей: «Открыть репозиторий…».
- **Клонирование** по URL (`https://…` или `git@…`) в выбранную папку с прогрессом.
- Создание репозитория (`git init`).
- «Обновить все репозитории» рабочей области одной командой.
- Контекстное меню: открыть в Terminal, показать в Finder, копировать путь, выкачать ветку.

### Изменения и коммиты
- Списки **Конфликты / В индексе / Изменения**, stage/unstage по файлу или все сразу.
- Diff файла, **добавление и отмена отдельных блоков (hunks)**.
- Отмена изменений: по файлу, все изменения, включая новые файлы.
- Добавление файла или расширения в `.gitignore`, stash отдельных файлов.
- Разрешение конфликтов: взять нашу/их версию, отметить как решённый; «Продолжить» и «Отменить операцию» для merge/rebase/cherry-pick.
- Коммит: **Amend**, **Commit и Push**, переключатель «Без хуков» (`--no-verify`).
- Индикаторы ahead/behind (коммиты к отправке и получению).

### История
- Список коммитов с подгрузкой, поиск по сообщению, режим «Все ветки».
- Подробности коммита: автор, родители, копирование хеша.
- Действия: checkout коммита (detached), создать ветку или тег, **cherry-pick**, **revert**, **reset** (`--soft`, `--mixed`, `--hard`).

### Ветки
- Локальные и удалённые ветки с фильтром.
- Checkout, создание (в том числе от выбранного коммита или ветки), переименование, удаление.
- **Merge** и **rebase** выбранной ветки в текущую.
- Fetch (`--all --prune`) и выкачивание ветки по имени; Pull в трёх режимах: merge, `--rebase`, `--ff-only`.
- Push и безопасный **force push** (`--force-with-lease`) с подтверждением.

### Stash, теги, remotes
- **Stash:** создать, Apply, Pop, Drop, создать ветку из stash.
- **Теги:** создать, checkout, push тега, удалить.
- **Remotes:** добавить, изменить URL, fetch, удалить.

### Хуки и Husky
- Просмотр и редактирование git-хуков прямо в приложении, переключатель «Исполняемый», ручной запуск хука.
- Определение Husky и его версии, инициализация Husky.
- Просмотр, смена и сброс `core.hooksPath`.
- Опция `HUSKY=0` для всех git-команд, которые выполняет приложение.

### Консоль
- Журнал всех git-команд, выполненных приложением, с кодом выхода.
- Собственные команды: `status`, `log --oneline -5` (префикс `git` необязателен); `!ls` выполняет обычную shell-команду.

### Обновления
- Фоновая проверка при запуске и раз в 6 часов: если вышла новая версия, вверху окна появляется баннер, на иконке в Dock — бейдж, а пункт меню меняется на «Доступна версия X — установить…».
- «Проверить обновления…» в меню приложения и в Настройках.
- Берёт последний релиз из GitHub Releases, показывает описание, по вашему подтверждению скачивает `.dmg`, заменяет приложение и перезапускает его.

## Горячие клавиши

| Действие | Клавиши |
|---|---|
| Открыть репозиторий | ⌘O |
| Добавить рабочую область | ⇧⌘O |
| Клонировать | ⇧⌘N |
| Обновить репозиторий | ⌘R |
| Пересканировать рабочие области | ⇧⌘R |
| Открыть в Terminal | ⇧⌘T |

## Настройки
- Терминал (Terminal, iTerm, Warp…).
- Глубина поиска репозиториев.
- Отключение Husky для операций из приложения.
- Репозиторий GitHub для обновлений.

## Сборка и релиз

```bash
./build.sh      # собирает универсальный (arm64 + x86_64) GitDeck.app
./package.sh    # упаковывает GitDeck.dmg
```

Версия приложения хранится в файле `VERSION`. Чтобы выпустить обновление: поднимите версию,
запустите `./package.sh` и создайте релиз с тегом `v<версия>` и приложенным `GitDeck.dmg`:

```bash
gh release create v1.1 GitDeck.dmg --title "GitDeck 1.1"
```

Сборка подписана ad-hoc, поэтому при первом запуске на другом Mac Gatekeeper может запросить подтверждение.
